# Startup Onboarding Platform

A simple backend and frontend application for managing startup onboarding. This application allows administrators to create, view, and manage startup profiles, including changing their acceptance status.

## Features

- Create new startup profiles
- View startup details
- Change startup acceptance status (Accepted/Rejected)
- Filter startups by status
- View all accepted startups

## Architecture

The application uses a Python backend with FastAPI and a simple frontend with HTML, CSS, and JavaScript:

- **Backend**: Python with FastAPI
- **Frontend**: HTML, Jinja2 templates, CSS, JavaScript
- **Data Storage**: In-memory database using Python objects

## Setup and Installation

### Prerequisites

- Python 3.8+

### Installation

1. Clone this repository
2. Create a virtual environment:
   ```
   python -m venv venv
   ```
3. Activate the virtual environment:
   - Windows: `venv\Scripts\activate`
   - Linux/Mac: `source venv/bin/activate`
4. Install dependencies:
   ```
   pip install fastapi uvicorn jinja2
   ```

### Running the Application

1. Make sure you have the JSON data file (`challenge3_data.json`) in the ***/static/data/*** directory
2. Start the application:
   ```
   python main.py
   ```
3. Open your browser and navigate to `http://localhost:5500`

## Usage Guide

### Dashboard
- The main dashboard shows all startups
- Use the filter buttons to filter startups by status

### Creating a Startup
1. Click "Create New Startup" in the navigation
2. Fill in the startup details
3. Add team members if needed
4. Click "Create Startup"

### Viewing and Managing a Startup
1. Click "View Details" on a startup card
2. View the startup information
3. Change the status using the "Accept" or "Reject" buttons

## Notes
- No actual database is used; all data is stored in memory
- The application will attempt to load initial data from `challenge3_data.json` if available
